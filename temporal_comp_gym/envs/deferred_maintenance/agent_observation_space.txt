# Deferred Maintenance Task - Observation Space

The agent receives a flattened 1D continuous array of observations at each time step. The environment is wrapped by `DeferredMaintenanceObservationWrapper` (in `wrappers.py`), which aggregates the raw dictionary data generated by `core.py` into the following structured vector:

## 1. Kinematics (6 values)
Provides the core physical state of the Rocket agent.
- `[0]` **pos_x**: Global X position in the physics space.
- `[1]` **pos_y**: Global Y position in the physics space.
- `[2]` **vel_x**: Current X axis velocity.
- `[3]` **vel_y**: Current Y axis velocity.
- `[4]` **angle**: Current rotation angle (in radians).
- `[5]` **ang_vel**: Current rotational angular velocity.

## 2. Micro-Navigation Sensors (8 or 9 values)
Provides spatial awareness of immediate surroundings to avoid hazards and navigate paths. The shape and output depend on the `spatial_sensor_type` parameter used upon environment creation.
- **If `raycasts` (8 values)**: Emits 8 simulated rays radially (every 45 degrees) outward from the rocket up to 150 pixels. Each value represents the normalized distance (0.0 to 1.0) to the first collision. A value of 1.0 indicates no obstacle was detected.
- **If `local_grid` (9 values)**: Samples a 3x3 grid around the rocket (using `cell_size` offsets). Each cell returns the `collision_type` ID of the shape occupying that space (e.g., `0.0` = Empty/Danger Void, `2.0` = Path Boundary, `3.0` = Code Zone, `4.0` = Station, `7.0` = Stage Boundary).

## 3. Macro-Navigation Waypoint (2 values)
- `[0]`, `[1]`: Currently reserved as a `[0.0, 0.0]` placeholder for future global direction hints (e.g., arrow to the stage exit).

## 4. Current Floor Code (1 value)
Indicates what type of interactable zone the rocket is currently touching.
- `0.0`: The agent is not touching any interactable zone.
- `>0.0`: The `color_code` / Type ID (e.g., `1.0`, `2.0`, `3.0`) of the `MaintenanceStation` or `CodeZone` the agent is currently overlapping. 

## 5. Action Readiness Indicator (1 value)
Tracks the cooldown/deferral mechanic that forces the agent to delay servicing codes.
- `0.0 (WAITING)`: Agent is mathematically locked out of servicing stations. Hovering over a station will yield a premature-service penalty.
- `1.0 (READY)`: Agent has traversed enough stages (based on `readiness_delay_range`) and is cleared to hover over matching stations to service codes and claim rewards.

## 6. Station Radar (X and Y per color type)
A dynamically sized segment (`max_code_types * 2` values) providing an internal compass mapping directly to all possible Maintenance Stations.
- For each code type ID `i` (from 1 to `max_code_types`), it returns two values: `[delta_x, delta_y]`.
- This represents the exact relative offset (`station_x - rocket_x`, `station_y - rocket_y`) to the closest station of that type.
- If a station of type `i` does not physically exist on the current map, the radar defaults to a null-indicator vector of `[-99.0, -99.0]`.
